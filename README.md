# Kaushalya Karnataka

## 📱 Project Overview
Kaushalya Karnataka is a real-time Android marketplace application designed to bridge the gap between local skilled workers and customers. It allows tradespeople to digitize their services and receive instant job requests through a highly responsive interface.

## ✨ Key Features
* **Real-Time Job Notifications:** Uses Firebase Firestore Snapshot Listeners to deliver instant "Hire Me" pop-up alerts to workers.
* **Secure Profile Management:** Implements ownership locks based on Firebase UID to prevent unauthorized profile editing.
* **Dynamic Worker Search:** Features a live-filtering system for quick service discovery.
* **Interactive Rating System:** Real-time 5-star community ratings synced with the cloud.

## 🛠 Tech Stack
* **Language:** Kotlin
* **Database:** Firebase Firestore (NoSQL)
* **Auth:** Firebase Authentication
* **UI:** Material Design, XML

## 🚀 How to Run
1. Clone this repository.
2. Open in Android Studio (Jellyfish or newer recommended).
3. Add your own `google-services.json` to the `app/` directory.
4. Build and Run on a device with API 24+.
